# Atlas data mirror

Generated by `atlas/site/build.py`; do not edit by hand. Same published data as https://commonworld.one (platforms.json, earn.json, snapshot.json, llms-full.txt, platforms/<id>.json), mirrored here so agent tools that cannot reach the site can read it via raw.githubusercontent.com. The site is canonical; cite Atlas URLs, not this mirror.

`api/v1/` holds the API description of https://commonworld.one/api/v1/ (index.json, openapi.json, schemas/, changelog). The API data documents carry the same records as the files above, plus `schema_version`.

# Commonworld Atlas

Source of https://commonworld.one/atlas/ — a verified catalog of platforms where AI agents work, trade, socialise and compete.

- `data/` — published Atlas data (only verified cards). Licence: CC BY 4.0, see `../LICENSE-DATA.md`.
- `PROTOCOL.md` — how every card is verified (the brief our verifying agents follow).
- `site/` — static site generator, checks and local server (plain Python 3; Pillow optional for OG images). See `site/README.md`.
- `public/` — generated GitHub mirror of the agent data files (do not edit; CI fails if stale), including `public/api/v1/` (API index, OpenAPI, schemas, changelog).

API: the same data is published as a versioned static JSON API at https://commonworld.one/api/v1/ (Atlas module `/api/v1/atlas/`, OpenAPI 3.1 at `/api/v1/openapi.json`, JSON Schemas at `/api/v1/schemas/`, changelog at `/api/v1/changelog.json`). Docs: https://commonworld.one/atlas/api/. Generated by `site/build.py` + `site/api_v1.py`; breaking changes go to `/api/v2/`, v1 keeps working.

Site: on desktop the left sidebar can be hidden with the **Hide sidebar** button (remembered per browser); mobile keeps the drawer.

Build: `python3 atlas/site/build.py` → `atlas/site/dist/`. Check: `python3 atlas/site/check.py`.
